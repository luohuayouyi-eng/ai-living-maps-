# AI 活地图 — 领域地图 v2.0（智能设计）

本仓库为「AI 活地图」静态站点。领域地图（DOMAIN MAP）已升级为 v2.0，主题：**智能设计 —— AI 辅助的产品与交互设计**。

## 快速预览

本地起服务后访问 `http://localhost:8765`（或任意静态服务器）：

```bash
python -m http.server 8765
```

- 主页：`/#/`
- 领域地图全景：`/#/map/domain`
- 各视图：`/#/map/domain/task`（典型任务）· `/#/map/domain/curriculum`（课程与能力）· `/#/map/domain/relations`（关系与依据）· `/#/map/domain/ai`（AI 助手）· `/#/map/domain/updates`（更新与来源）
- 节点深链：`/#/map/domain/node/<id>`，如 `node/c-diffusion`、`node/t-lora`

## 领域地图内容（对应作业要求四）

| 要求 | 实现 |
|---|---|
| 内容完整 | 五层节点库：问题 6 · 概念 10 · 方法 8 · 工具 10 · 资源 7 = **41 节点** |
| 知识与工具连接 | 每节点：能完成的任务 / 背后的概念 / 使用前需要 / 对应课程 / 适用条件 / 主要局限 / 替代方案 / 来源 |
| 课程关联 | 7 条「培养要求→能力→课程→概念/工具→后续实践」链条，课程号依据浙大 2019 级工业设计培养方案；覆盖程度 5 级；不可核实标注「待核实」 |
| 理解程度 | 每节点标注 已初步理解 / 已经尝试 / 待深入学习 |
| 关系与依据 | 17 条带类型与依据的关系边（依赖/并列/替代/协同/扩展/互补）+ 跨地图关联 |
| 可更新、有记录 | 29 条来源（含核实状态）、4 条更新记录（日期/对象/依据/修改/原因）、局限 5 条、后续计划 4 条 |
| AI 能力服务地图 | AI 助手：概念检索 / 路线对比 / 学习路径，全部基于地图数据做确定性检索，**不调用外部模型、不索取 API 密钥** |

## 文件说明

```
index.html               主页（原版，未改动）
css/style.css            原站样式（未改动）
css/domain.css         ★ 领域地图样式
js/app.js              ✎ 原站逻辑 + 2 处补丁（路由支持子路径深链；进入领域地图时动态加载资源）
js/domain.js           ★ 领域地图渲染器 + AI 助手 + 课程对照表
data/maps.json         ✎ domain 卡片标题/描述更新
data/domain.json       ★ 领域地图元数据（任务流 / 课程链条 / 关系 / 来源 / 更新记录）
data/domain-nodes.json ★ 五层 41 节点库
public/                  同一份站点的镜像副本（与根目录内容同步）
cognitive-map/           认知地图独立页面（未改动）
```

## 更新方式

1. 改 `data/domain-nodes.json` / `data/domain.json`（注意保持 JSON 合法）；
2. 同步 `public/` 下对应副本；
3. 提交推送后在 Gitee Pages 重新部署（或接入的其它托管方自动构建）。
